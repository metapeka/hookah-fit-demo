# Вентиляция кальянной — расчёт и нормы

Одностраничный калькулятор-советник: приток, вытяжка, CO, калорифер, воздуховод. Со ссылками на документы и пунктами, на которые опирается каждое число.
Чистый HTML/CSS/JS, без сборки и зависимостей.

## Что считает

- Приток по кратности и по гостям, местные отсосы, вытяжка с подпором 5%.
- Расход по CO: E = 2,3 г/ч на кальян (Daher 2010), C = E·N/L, цель по ПДКмр 5 мг/м³.
- Максимум кальянов при текущем расходе.
- Мощность нагрева притока зимой.
- Диаметр магистрали по табл. Л.1 СП 60 при 3 м/с.
- Советник: что поймано расчётом, что проверить замером.

## Документы на странице

Приказ 32/пр/33, СанПиН 1.2.3685-21, ФЗ-15, СП 60.13330.2020, СП 118.13330.2022, СП 51.13330.2011, СП 73.13330.2016, ГОСТ 34060-2017, Приказ Минстроя 344/пр, СанПиН 2.3/2.4.3590-20. Статус проверен 28.11.2026.
