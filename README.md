# Приточка кальянной — демо

Одностраничный калькулятор: сколько притока нужно залу с кальянами, сходится ли баланс и что писать заказчику.
Чистый HTML/CSS/JS, без сборки и зависимостей. Открывается локально или через GitHub Pages.

## Что считает

- Приток по площади и кратности, по гостям, по вредностям от кальянов — берётся максимум.
- Вытяжка от точек у столов и общая.
- Баланс приток/вытяжка: где разрежение и дверь «засосёт».
- Приток на м², м³/с для подбора вентилятора.

## Где править нормы

`index.html`, блок «Исходные нормы»: кратность, м³/ч на гостя, вытяжка от точки, расход угля.
Числа по умолчанию — стартовые, не замена проекту.
